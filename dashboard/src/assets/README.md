# Assets

## `discord-mark.svg` (not added yet)

The "Continue with Discord" button shows Discord's official mark when this file
exists, and a neutral sign-in icon until then. No code change is needed.

1. Download the official mark from Discord's brand page (https://discord.com/branding).
2. Save it here as `discord-mark.svg`. A single-colour dark mark reads best on the
   cyan button.
3. Follow Discord's brand guidelines. Don't redraw, recolour or distort it.
