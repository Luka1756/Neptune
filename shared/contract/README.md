# contract

This folder is for the backend's OpenAPI schema snapshot (for example
`openapi.json`).

- It is **produced by the backend**, not written by hand.
- The dashboard generates its TypeScript types from it.
- Do not add endpoints here independently. Requests for new capabilities go
  through [`../../docs/contract-workflow.md`](../../docs/contract-workflow.md).

No snapshot has been published yet.
